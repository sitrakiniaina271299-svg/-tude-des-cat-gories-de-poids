# Etude-des-categories-de-poids
## 1. Présentation du projet

Ce projet consiste à réaliser une analyse statistique des différentes catégories de poids à partir d'un jeu de données.
L'objectif est d'explorer les données, d'identifier les relations entre les variables

## 2. Objectifs

- Explorer et nettoyer les données.
- Réaliser une analyse descriptive.
- Visualiser les données.
- Étudier les relations entre les variables (tests statistiques).
- Interpréter les résultats.

## 3. Outils utilisés

- R
- RStudio
- R Markdown
- Librairie : tidyverse, FSA, DescTools

## 4. Méthodologie

- Analyse descriptive
- Visualisation des données
- Test de Krsukal-Wallis
- Tests du Khi-deux
- Résidus standardisés ajustés
- V de Cramér
